# Contributing to Tarmudi Fest

Thank you for your interest. The repository is currently in **STEP 00 (documentation-only)**.

1. Before a contribution, check open GitHub Issues and the locked PRD baseline.
2. Do not change locked business requirements casually; open a change-request issue explaining motivation, impact, acceptance tests, and affected users.
3. Proposed branch pattern: `feature/<short-name>`, `fix/<short-name>`, `docs/<short-name>` branching from `develop`.
4. Open a pull request containing problem description, scope, screenshots for UI changes, test results, risks, and privacy considerations.
5. Never submit production data, any child's personal details, private email lists, secrets, or official branding that you do not have rights to distribute.
6. Accessibility and mobile-first design matter: test narrow phones, labels, focus, contrast, and failure states.
7. Follow the contributor code of conduct. Do not post vulnerabilities as public issues; follow `SECURITY.md`.
